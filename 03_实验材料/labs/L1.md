## 操作步骤

第一步，画出一个帧从空闲到驻留、可替换、写回和重新分配的状态变化。第二步，在 S01.Q02 的标记区域实现访问位更新与候选选择，逐项检查 pin 资格。第三步，用 2 帧模型推演下表；若课前已提供独立夹具，将同一序列编码为断言。第四步，再追踪候选结果如何进入 S01.Q04，分析并发同页调入和失败发布。

| 检查项 | 输入或调度 | 预期事实 |
| --- | --- | --- |
| BUF01 全 pin | pin A；pin B；请求 C | 不替换 A/B；返回无候选或接口定义的失败 |
| BUF02 脏状态合并 | 修改 A；unpin A；再次 pin/unpin(false) | A 仍需写回，false 不清除已有修改 |
| BUF03 写回失败 | A 脏且可淘汰；注入写失败；请求 C | 不发布 C 成功映射；A 最新内容未丢失 |
| BUF04 同页调入 | 两线程同时请求不驻留的 A | 只有一个有效驻留映射；各自 pin 正确 |
| HEAP01 槽复用 | 插入、逻辑删除、满足回收条件后复用 | 未达到回收条件的版本不被覆盖 |
| HEAP02 空间边界 | 页剩余空间刚好不足记录与槽开销 | 插入失败且页结构与可用空间一致 |

不要为得到固定淘汰页而假定所有实现有相同初始时钟指针。若验证具体选择顺序，夹具应显式固定指针、候选次序和访问位；若只验证资格，则对“未选中 pinned 帧”断言。关闭重开测试还需文件 I/O 配套，不能用内存副本充当持久化证据。

## 常见错误定位

返回旧内容时先检查脏位是否被 false 覆盖，再检查淘汰前写回是否成功。全 pin 时仍返回候选，检查候选算法是否把访问位当作 pin。并发同页出现两帧，检查加载状态的协调和映射发布，而不是只在最终页表外层加锁。
