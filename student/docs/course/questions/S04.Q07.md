# S04.Q07 ANALYZE 与统计维护

[返回阶段指南](../stages/S04.md)｜[题目总览](../README.md)

本题尚未注册独立单元测试；下列现有测试是阅读和集成验证素材，完成后需由课程维护者补齐隔离注册。

## 这题要解决什么

ANALYZE 扫描含 NULL 和长字符串的表时，既要以固定种子得到可复现的有界样本，也要把结果校验、安装并在数据或模式改变后失效。只算出数值而不维护目录状态仍是不完整实现。

完成后，你能协调采样、列统计和 CatalogStore 生命周期，覆盖空表与全 NULL 列。

## 先走通一个小例子

固定种子扫描含 NULL 和长字符串的表。两次 ANALYZE 要得到可复现的有界样本；修改数据或模式后旧统计必须失效或被正确替换。

## 分步实现

- 建容量受限累加器，逐行观察而不保存整表。
- 从样本计算既有 NULL、宽度、不同值统计。
- 校验后安装到 CatalogStore。
- 维护执行器协调 ANALYZE 和失效。

## 必须守住的约束

- 固定种子下样本必须可复现。
- 空表和全 NULL 列也要产生一致统计。
- 使用既有格式，不新增成本模型。

## 怎样验证

验收必须覆盖：采样容量；固定种子可复现；空表/NULL；数据/模式变化后统计代数正确。

现有素材 [statistics_test.cpp](../../../libs/catalog/tests/statistics_test.cpp)、[store_test.cpp](../../../libs/catalog/tests/store_test.cpp) 可能跨越多题，不能把它们当作本题已经注册的隔离测试。完成后按课程规定的单元入口验证；独立注册状态是 `pending-isolated-test-registration`。
