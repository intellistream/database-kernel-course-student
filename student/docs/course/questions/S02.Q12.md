# S02.Q12 COPY 文本导入

## 这题要解决什么

COPY 需要把不规则文本可靠转换为成批的表行，并把字段错误与实际变更边界连起来，避免导入器把不完整输入当作正常数据。

## 开始前读懂什么

COPY 文本行/字段边界、NULL 与转义的解码、批次缓存，以及与变更端口的原子性边界。本题使用的夹具契约见[夹具说明](../fixtures.md)：F-IO、F-MUTATION，它们说明验收输入/端口边界，并不意味着仓库中普遍已有同名可直接实例化的类。阅读相关知识只是建立语境，不要求先完成关联题目。

## 先走通一个小例子

输入包含空字段、转义分隔符和 NULL 表示时，应映射到正确目标列。坏转义或半行要报错；批次中某行失败时，最终可见性遵从给定事务端口的完整组合边界。

先在纸上标出输入、应返回的状态和需要保留的资源；这比一开始扩展到完整工作负载更容易发现边界错位。

## 分步实现

1. 先按格式读取行与字段，避免把转义分隔符切成两列。
2. 把 NULL、转义和普通文本转换为带类型的待写值。
3. 按目标列映射积累有限批次，并在边界 flush。
4. 将堆和索引更新接到变更端口，统一传播坏行和提交失败。

每完成一步都回到 marker 附近检查调用方期待的是值、错误还是 guard/自有对象；不要把相邻题的策略或事务规则塞进这里。

## 必须守住的约束

字段缓冲不能借用下一行会覆盖的文本；半行、坏转义和类型错误必须带回失败。此题复用事务端口，不自行定义提交规则；失败时不得把未完成批次宣称为成功。

## 怎样验证

验收必须覆盖以下全部检查：

- 空字段和转义
- 坏行/半行
- 批量错误传播
- 完整组合中的失败原子性
