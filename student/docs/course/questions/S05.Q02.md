## 这题要解决什么

分组输入 `(NULL,1),(NULL,1),(0,1),(NULL,2)` 应得到三个组；即使不同键发生哈希碰撞，也不能被合并。

完成后，你能实现多列类型化组键的哈希和结构相等、组创建/扩容与状态所有权，并保留规定的首次出现顺序。

## 先走通一个小例子

输入 `(NULL,1),(NULL,1),(0,1),(NULL,2)`，应形成三个组；再制造不同键相同哈希，确认结构比较仍能区分。

## 分步实现

- 定义多列组键的类型化相等与哈希。
- 先查找已有组，否则创建并拥有其状态。
- 处理桶增长与碰撞，不改变逻辑组。
- 按契约保留首次出现的输出次序。

## 必须守住的约束

- NULL 是组键可相等成员，规则不同于普通 SQL 比较。
- FLOAT 采用要求的位表示。
- 组状态的所有权必须随表生命周期释放。

## 怎样验证

验收必须覆盖：NULL 组键；复合键；碰撞与扩容；FLOAT 位表示；首次出现顺序契约。
