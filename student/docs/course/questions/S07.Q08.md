# S07.Q08 子查询规划与安全改写

[返回阶段指南](../stages/S07.md)｜[题目总览](../README.md)

本题尚未注册独立单元测试；下列现有测试是阅读和集成验证素材，完成后需由课程维护者补齐隔离注册。

## 这题要解决什么

嵌套子查询引用外层列时，绑定器必须记录正确的相关深度和参数域；若改写为连接不能证明保留 NULL、重复行或标量基数，就应维持子计划。

完成后，你能解析/绑定子链接、重写安全的外部引用并降低子计划，同时保守地拒绝不安全改写。

## 先走通一个小例子

嵌套查询引用外层列时，应在正确深度绑定为相关引用；若安全改写无法保持 NULL/重复行语义，必须保留子计划而非强改。

## 分步实现

- 解析并绑定 Scalar/EXISTS/IN 子链接，限制单列处。
- 发现跨层外部引用并分配参数命名空间。
- 重写可安全的外部引用为子计划输入参数。
- 降低为子计划或仅在参考支持条件下安全改写。

## 必须守住的约束

- 参数不能越过所属查询域。
- 不能改写的情形必须保留子计划。
- 保留 NULL、重复行和基数语义，不扩展题目以外 JOIN。

## 怎样验证

验收必须覆盖：跨层相关引用；不能改写的情形保持子计划；NULL/重复行不变；参数不越域。
