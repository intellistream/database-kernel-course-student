# S06.Q03 全行 Unique

[返回阶段指南](../stages/S06.md)｜[题目总览](../README.md)

本题已经注册并验证隔离单元测试；初始挖空实现会失败，完成本题区域后再以该入口验证。

## 这题要解决什么

全行去重只能比较固定 schema 的完整类型化行：两列 `(NULL::INT,1)` 的重复应保留首次行；单列 `-0.0` 与 `+0.0` 是否相同则遵循规定的位表示。

完成后，你能定义行哈希与结构相等，惰性跳过重复，并为 SELECT DISTINCT 和 UNION DISTINCT 提供无残留的生命周期。

## 先走通一个小例子

先以两列 schema 输入 `(NULL::INT,1),(NULL::INT,1)`，只保留第一行。另以单列 FLOAT schema 输入 `(-0.0),(+0.0)`，按规定的位表示区分；第二次执行不能看到旧集合。

## 分步实现

- 定义完整行的逐列类型化相等与哈希。
- open 时清空已见状态。
- next 惰性读取，跳过已见行并保留第一行。
- rescan 后重置集合；lowering 为 SELECT DISTINCT/UNION DISTINCT 接入该节点。

## 必须守住的约束

- 比较全行而非某一列，类型化 NULL 必须参与结构规则。
- FLOAT 按位表示，不能偷换为 SQL 比较。
- 本题不是聚合 DISTINCT。
