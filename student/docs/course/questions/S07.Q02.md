# S07.Q02 嵌套循环连接

[返回阶段指南](../stages/S07.md)｜[题目总览](../README.md)

## 这题要解决什么

外侧 `[1,2]` 和内侧 `[1,1,3]` 等值连接时，键 1 要产生两行；每取到一条外行都要正确重扫内侧，空侧又不能产生无关读取。

完成后，你能实现嵌套循环的行推进、条件真值、组合输出、清理与 rescan。

## 先走通一个小例子

外侧 `[1,2]` 与内侧 `[1,1,3]` 按条件相等连接，输出两条 1 的匹配；内侧为空时不应反复读取无关输入。

## 分步实现

- open 建立两侧状态。
- 为每个外行绑定当前行并重扫内侧。
- 逐个内行计算条件，仅 TRUE 时组合输出。
- 实现 EOF、rescan 和失败清理。

## 必须守住的约束

- NULL/非等值条件仍按表达式真值处理。
- 多对多重复必须全部输出。
- 空侧和错误路径不能泄漏状态。

## 怎样验证

验收必须覆盖：空侧不读无关子节点；多对多重复键；非等值/NULL；重扫与错误清理。
