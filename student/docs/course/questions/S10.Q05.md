# S10.Q05 整页镜像、压缩与 delta

[返回阶段指南](../stages/S10.md)｜[题目总览](../README.md)

验收状态：本题的独立测试登记尚待补齐；现有测试只作素材，夹具名只表示契约。

## 这题要解决什么

页面变更的 WAL 既要可恢复，也要控制体积。本题在 checkpoint epoch 边界决定何时生成或复用 FPI，按给定格式选择洞区与压缩，并生成/验证 page delta。字段 codec 已给定；真正需要学生决定的是镜像、压缩、差分和发布的条件，最终必须能重建原始页字节。

## 开始前读懂什么

阅读 FPI 标记、page LSN、checkpoint epoch、压缩接口和 `PageDelta` 的边界契约；理解 FPI 是恢复的替换候选，delta 是有范围限制的增量。记录 framing 的编码不是本题要另造的格式。

## 从哪里开始

从 [manager_page_images.cpp](../../../libs/wal/src/manager_page_images.cpp) 与 [manager.cpp](../../../libs/wal/src/manager.cpp) 看 FPI 决策和缓存；[compression.cpp](../../../libs/wal/src/compression.cpp)、[delta.cpp](../../../libs/wal/src/delta.cpp)、[record_image.cpp](../../../libs/wal/src/record_image.cpp) 负责数据变换。命令：`rg -n 'LAB-S10\.Q05:.*-BEGIN' libs`。

## 先走通一个小例子

在新 checkpoint epoch 内首次修改一页，记录需要按策略带 FPI；第二次修改同页可按条件复用已保护事实。对一段高重复字节选择压缩，对不可压缩内容回退到合法表示；再应用生成的 delta，结果必须逐字节等于目标页。提供越界或重叠补丁时，应在发布前拒绝。

## 分步实现

1. 维护页与 checkpoint epoch 的 FPI 资格及复用判定。
2. 实现洞区处理、压缩尝试和合法的回退选择。
3. 生成与应用带范围检查的 delta，拒绝非法布局。
4. 将 FPI/delta 与记录构造、页 LSN 和后续发布顺序连接起来。

## 实现约束

- checkpoint epoch 边界不能混淆，FPI 决策必须可由恢复信任。
- 压缩失败、无收益或解压失败不能伪造有效映像。
- delta 重建须与原页字节一致，非法差分不改变候选页。

## 怎样验证

覆盖检查点 epoch 边界、可压缩/不可压缩、非法差分、重建与原页字节一致。现有 [compression_test.cpp](../../../libs/wal/tests/compression_test.cpp)、[delta_test.cpp](../../../libs/wal/tests/delta_test.cpp)、[record_test.cpp](../../../libs/wal/tests/record_test.cpp) 是素材；独立注册待补齐。

## 思考题

- 为什么同一页跨越 checkpoint epoch 后不能盲目沿用旧的 FPI 决策？
- 一条 delta 在何种情况下能保证不读越输入或输出页范围？

## 延伸阅读

比较压缩策略时，除了长度还要保存能否完全解码的证据；长度更短却不能恢复原字节的表示没有价值。对 delta 也应先验证所有范围，再一次提交结果，避免半个补丁污染候选页。
