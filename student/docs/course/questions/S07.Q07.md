# S07.Q07 子计划求值与相关参数

[返回阶段指南](../stages/S07.md)｜[题目总览](../README.md)

本题尚未注册独立单元测试；下列现有测试是阅读和集成验证素材，完成后需由课程维护者补齐隔离注册。

## 这题要解决什么

Scalar、EXISTS、IN 与 NOT IN 子计划要分别处理空输入、类型化 NULL、标量多行错误和成员集合中的 NULL；关联参数变化后旧结果必须清理。

完成后，你能驱动子计划生命周期、计算三类表达式结果，并区分无关联缓存复用与关联重扫。

## 先走通一个小例子

Scalar 子计划空结果应返回类型化 NULL，多行应报基数错误；`NOT IN (1,NULL)` 对不匹配值应为 UNKNOWN。换外行绑定相关参数后，旧结果必须清理；无关联子计划才可复用缓存。

## 分步实现

- open/close 子节点并管理缓存边界。
- 分别实现 EXISTS、Scalar 和成员资格扫描。
- 记录成员候选及 NULL 影响，形成 IN/NOT IN 真值。
- 绑定关联参数，清理后 rescan。

## 必须守住的约束

- 空 Scalar 不是无类型 NULL。
- Scalar 多行必须拒绝。
- NOT IN 的 UNKNOWN 不能与 FALSE 混同。

## 怎样验证

验收必须覆盖：空标量为类型化 NULL；多行标量拒绝；NOT IN 的 UNKNOWN；相关参数与缓存重置。
