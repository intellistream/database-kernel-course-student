## 这题要解决什么

三分支 `SELECT NULL UNION SELECT 1 UNION SELECT 2.5 ORDER BY 1` 需要保留左结合，求每层共同类型，并在集合输出作用域解释名称和序号排序。

完成后，你能把 UNION 语法绑定为列数一致、类型明确、列名稳定的集合树，并拒绝不兼容分支。

## 先走通一个小例子

解析三分支 `SELECT NULL UNION SELECT 1 UNION SELECT 2.5 ORDER BY 1`，检查左结合、共同类型、左侧列名和全局序号排序；再尝试列数不同。

## 分步实现

- 将集合语法投影为合适 AST，并保留括号/左结合。
- 分别绑定分支，检查列数和共同类型。
- 处理 UNKNOWN、参数已知类型及左侧输出名。
- 在集合输出作用域绑定全局 ORDER BY 名称或序号。

## 实现约束

- 各分支不能独立决定互不兼容的最终类型。
- 全 UNKNOWN 仍须按题目契约处理。
- 局部与全局排序作用域不同。
