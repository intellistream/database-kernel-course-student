# S06.Q04 集合计划与输入适配

## 这题要解决什么

UNION 的分支 DISTINCT、类型适配、集合 DISTINCT 和局部/全局 LIMIT 位于不同树层。把转换放到错误一层会改变哪些行被判为重复。

完成后，你能保留集合层次，组合 Append/Unique，并为各分支建立正确输出描述符。

## 先走通一个小例子

两个分支先各自做局部 DISTINCT/LIMIT，再按共同类型适配，最后 UNION DISTINCT。观察转换若放错层会改变重复判定。

## 分步实现

- 预处理集合树，保留分支和集合层级。
- 分别降低分支局部排序/窗口与输入适配。
- 以 Append 连接分支，DISTINCT 时再加 Unique。
- 处理 INSERT SELECT 和聚合分支的输出描述符。

## 必须守住的约束

- 分支 DISTINCT 后才转换；集合 DISTINCT 前转换。
- 局部 LIMIT 不得错误变为全局 LIMIT。
- 不要假设 Append/Unique 之外的题已实现。
