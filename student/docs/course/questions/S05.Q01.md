# S05.Q01 标量聚合累加器

## 这题要解决什么

聚合器遇到空输入、全 NULL、`COUNT(*)` 和边界数值时，初始状态、逐行累加和 finish 规则各不相同；把未见值当作零会立即破坏 SQL 语义。

完成后，你能为 COUNT、SUM、AVG、MIN、MAX 定义明确状态转移，处理 NULL、溢出、FLOAT 与重置。

## 先走通一个小例子

分别喂入空输入、全 NULL、`COUNT(*)` 和接近边界的整数/浮点。观察各聚合的初值、逐行变化、finish 值以及 reset 后是否干净。

## 分步实现

- 为每种聚合确定空状态和接收一行后的状态。
- 分开处理 COUNT(*)、值参数和 NULL。
- 实现 SUM/AVG 的宽累加或浮点规则及 MIN/MAX 比较。
- 在 finish 和 reset 处收束并清理状态。

## 实现约束

- COUNT(*) 不读取参数 NULL。
- 空输入与全 NULL 的输出要符合各聚合契约。
- 整数溢出、FLOAT 特殊值和重置都不能含糊。

## 怎样验证

验收必须覆盖：全 NULL 与空输入；COUNT(*)；SUM/AVG 边界；重置后不混入旧值。

现有素材 [aggregate_test.cpp](../../../libs/execution/tests/aggregate_test.cpp) 可能跨越多题，不能把它们当作本题已经注册的隔离测试。完成后按课程规定的单元入口验证；独立注册状态是 `pending-isolated-test-registration`。
