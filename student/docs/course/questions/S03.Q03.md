# S03.Q03 插入、分裂与新根

[返回阶段指南](../stages/S03.md)｜[题目总览](../README.md)

## 这题要解决什么

插入空间不足时，树必须把数据和导航信息分裂并逐层传播，最终安全发布新根。这里保证结构增长时仍可被并发访问和恢复。

## 开始前读懂什么

叶/内部节点分裂、兄弟链接和 high key、父级传播与新根发布，以及并发插入重试。本题使用的夹具契约见[夹具说明](../fixtures.md)：F-TREE、F-WAL，它们说明验收输入/端口边界，并不意味着仓库中普遍已有同名可直接实例化的类。阅读相关知识只是建立语境，不要求先完成关联题目。

## 先走通一个小例子

持续插入直到叶分裂，再继续使内部节点和根增长；同键不同 RID 都应保留。分裂或页分配失败后，树仍能从根遍历；并发插入看见未完成分裂时能协助或重试。

先在纸上标出输入、应返回的状态和需要保留的资源；这比一开始扩展到完整工作负载更容易发现边界错位。

## 分步实现

1. 先在叶页规划原地插入和容量检查。
2. 容量不足时选择合法分裂点，写新页、分隔键和双向链接。
3. 向父级传播分裂，处理父级也满及创建新根。
4. 处理 incomplete split、root hint 与重试，检查所有发布顺序。

每完成一步都回到 marker 附近检查调用方期待的是值、错误还是 guard/自有对象；不要把相邻题的策略或事务规则塞进这里。

## 必须守住的约束

非唯一索引允许同键多 RID；分裂前后叶链和 high key 必须可导航。新根只能在完整子结构后发布，失败或竞争不能留半链、悬挂父指针或持有 guard。
