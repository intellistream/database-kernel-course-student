# S02.Q07 基础算子与投影生命周期

[返回阶段指南](../stages/S02.md)｜[题目总览](../README.md)

## 这题要解决什么

基础执行节点要把各种行来源组织成一致的生命周期，并在过滤和投影后交付自有输出。这是排序、DML 等上层算子的共同地基。

## 开始前读懂什么

PlanState 生命周期、子节点资源拥有关系、谓词只接受 TRUE，以及投影输出的独立所有权。本题使用的夹具契约见[夹具说明](../fixtures.md)：F-ROWS、F-AST，它们说明验收输入/端口边界，并不意味着仓库中普遍已有同名可直接实例化的类。阅读相关知识只是建立语境，不要求先完成关联题目。

## 先走通一个小例子

扫描三行，谓词结果分别为 TRUE、FALSE、UNKNOWN，只有第一行输出。子节点到 EOF 后重复 next 稳定返回结束；open 在中途失败时不保留已开资源，换参数后 rescan 重新遍历。

先在纸上标出输入、应返回的状态和需要保留的资源；这比一开始扩展到完整工作负载更容易发现边界错位。

## 分步实现

1. 先统一 open/next/rescan/close 的状态转换。
2. 实现 Values、Result 和扫描的取行循环，并只放行 TRUE。
3. 让投影把结果写进自有行缓冲，不借用端口页。
4. 补齐 IndexScan 端口配置及错误清理，再检查复扫。

每完成一步都回到 marker 附近检查调用方期待的是值、错误还是 guard/自有对象；不要把相邻题的策略或事务规则塞进这里。

## 必须守住的约束

FALSE 与 UNKNOWN 都要过滤；EOF 必须稳定。输出行不能引用即将移动或释放的扫描页，部分 open 失败要关闭已打开的子资源。

## 怎样验证
