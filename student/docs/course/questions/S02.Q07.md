# S02.Q07 基础算子与投影生命周期

[返回阶段指南](../stages/S02.md)｜[题目总览](../README.md)

**独立测试：**待配置。

## 这题要解决什么

基础执行节点要把各种行来源组织成一致的生命周期，并在过滤和投影后交付自有输出。这是排序、DML 等上层算子的共同地基。

## 开始前读懂什么

PlanState 生命周期、子节点资源拥有关系、谓词只接受 TRUE，以及投影输出的独立所有权。本题使用的夹具契约见[夹具说明](../fixtures.md)：F-ROWS、F-AST，用于说明输入和依赖端口。

## 从哪里开始

本题源码入口是 [heap_index_scan_port.cpp](../../../libs/engine/src/heap_index_scan_port.cpp)、[heap_seq_scan_port.cpp](../../../libs/engine/src/heap_seq_scan_port.cpp)、[operators.cpp](../../../libs/execution/src/operators.cpp)、[projection_program.cpp](../../../libs/execution/src/projection_program.cpp)、[projection_program.hpp](../../../libs/execution/src/projection_program.hpp)、[scan_state.cpp](../../../libs/execution/src/scan_state.cpp)。优先定位 `ValuesState`/`ResultState` 的 `do_open`、`do_next`、`do_rescan`，以及 `ProjectionProgram::compile`、`evaluate` 和 `HeapSeqScanPort::open`、`next`、`rescan`。实现范围为本题 marker 包围的区间；在仓库根目录检索：

## 先走通一个小例子

扫描三行，谓词结果分别为 TRUE、FALSE、UNKNOWN，只有第一行输出。子节点到 EOF 后重复 next 稳定返回结束；open 在中途失败时不保留已开资源，换参数后 rescan 重新遍历。

先在纸上标出输入、应返回的状态和需要保留的资源；这比一开始扩展到完整工作负载更容易发现边界错位。

## 分步实现

1. 先统一 open/next/rescan/close 的状态转换。
2. 实现 Values、Result 和扫描的取行循环，并只放行 TRUE。
3. 让投影把结果写进自有行缓冲，不借用端口页。
4. 补齐 IndexScan 端口配置及错误清理，再检查复扫。

每步实现后检查调用方的返回类型、错误和对象生命周期。

## 实现约束

FALSE 与 UNKNOWN 都要过滤；EOF 必须稳定。输出行不能引用即将移动或释放的扫描页，部分 open 失败要关闭已打开的子资源。

## 怎样验证

检查以下场景：

- 仅 TRUE 通过
- 输出所有权
- 稳定 EOF
- 部分打开失败清理
- 参数变化后重新扫描
