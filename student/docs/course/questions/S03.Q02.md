# S03.Q02 B+Tree 下降与定位

## 这题要解决什么

树的读路径不能假定并发分裂从未发生；它需要借助 high key 和 right link 修正下降过程，稳定地到达目标叶。

## 开始前读懂什么

根到叶的读下降、high key/right link 对并发分裂的修正，以及空树与边界键的定位语义。本题使用的夹具契约见[夹具说明](../fixtures.md)：F-TREE，用于说明输入和依赖端口。

## 先走通一个小例子

在多层树中查找边界键，应到达包含其下界的叶。读取到一个 high key 已不覆盖目标的页时，要沿 right link 修正；空树和不存在键分别给出可区分的正常定位结果。

先在纸上标出输入、应返回的状态和需要保留的资源；这比一开始扩展到完整工作负载更容易发现边界错位。

## 分步实现

1. 先从元页/根取得读 guard，并验证页角色。
2. 按分隔键选择子页，在内部层逐层下降。
3. 每层检查 high key，必要时右移后重新判断。
4. 把最终叶位置交给扫描或插入调用者，并清理过期 guard。

每步实现后检查调用方的返回类型、错误和对象生命周期。

## 实现约束

读到分裂中的页不能信任旧路径；right link 修正不能跳过可能目标。空树与不存在键不是损坏，guard 的替换必须先取得新页再释放旧页。

## 怎样验证

检查以下场景：

- 多层树
- 边界键
- 读到分裂中的节点
- 空树与不存在的键
