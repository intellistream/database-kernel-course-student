# S03.Q04 范围扫描与游标

[返回阶段指南](../stages/S03.md)｜[题目总览](../README.md)

**独立测试：**待配置。

## 这题要解决什么

索引扫描要把 SQL 风格的边界解释成连续的键范围，并跨越叶页返回每个候选。游标正确释放资源才能供执行器安全重用。

## 开始前读懂什么

下界/上界及开闭端点、复合键前缀范围、跨叶游标推进，以及 rescan 和提前结束时的 guard 生命周期。本题使用的夹具契约见[夹具说明](../fixtures.md)：F-TREE，用于说明输入和依赖端口。

## 从哪里开始

本题源码入口是 [btree_relation.cpp](../../../libs/access/src/btree_relation.cpp)、[btree_scan.cpp](../../../libs/access/src/btree_scan.cpp)。优先定位 `BtreeScan::for_range`、`for_eq_range`、`next_candidate`、`previous_candidate`、`rescan`，以及 `Impl::before_lower`、`after_upper`、`step_leaf`。实现范围为本题 marker 包围的区间；在仓库根目录检索：

```sh
rg -n 'LAB-S03\.Q04:.*-BEGIN' libs
```

## 先走通一个小例子

范围 `[a, a]` 只含等于 a 的条目；矛盾端点直接为空。重复键跨两个叶页时扫描不能漏项，提前停止后页 guard 释放；rescan 换范围后从新边界重新开始。

先在纸上标出输入、应返回的状态和需要保留的资源；这比一开始扩展到完整工作负载更容易发现边界错位。

## 分步实现

1. 先编码边界并判定空范围、方向和端点开闭。
2. 下降到初始叶，再在页内跳过下界前条目。
3. 跨 right/left 链推进并在每个候选上检查上界。
4. 实现 rebind/rescan 与早停清理，避免保留旧叶。

每步实现后检查调用方的返回类型、错误和对象生命周期。

## 实现约束

复合前缀不能被当作完整键比较；上、下界相等时开闭决定结果。跨叶重复键必须完整返回，EOF 与提前 close 后不得持有页 guard。

## 怎样验证

检查以下场景：

- 端点相等/矛盾
- 跨多叶重复键
- rescan 重设范围
- 提前结束释放守卫

现有测试源码可作为场景素材：[btree_scan_bounds_test.cpp](../../../libs/access/tests/btree_scan_bounds_test.cpp)、[btree_relation_scan_test.cpp](../../../libs/access/tests/btree_relation_scan_test.cpp)。测试范围见对应源码。独立注册待补齐；补齐后可在仓库根目录运行 `python3 labs/run.py unit S03.Q04`，并以实际报告为准。可先运行 `python3 labs/run.py list --stage 03` 核对登记状态。
