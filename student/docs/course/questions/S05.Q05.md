## 这题要解决什么

聚合执行器在空输入时，全局聚合要输出一行，分组聚合输出零行；HAVING 为 FALSE 或 UNKNOWN 时也不能输出。异常中断和第二次执行同样要保持状态完整。

完成后，你能协调输入、组表、累加器和最终输出的生命周期，正确处理空输入、HAVING、清理与 rescan。

## 先走通一个小例子

空输入时全局聚合应产一行，带 GROUP BY 则零行；让 HAVING 得到 FALSE 与 UNKNOWN，二者均不输出。随后 rescan。

## 分步实现

- 在 open 建立输入、组表和累加器生命周期。
- 读取输入并按组送入累加状态。
- 按空输入规则补全全局组。
- finish 后计算 HAVING，仅 TRUE 输出，并支持 rescan/失败清理。

## 实现约束

- HAVING 只有 TRUE 能通过。
- 全局空输入和分组空输入行数不同。
- 任何中途错误都应关闭和释放已打开状态。

## 怎样验证

验收必须覆盖：全局空输入一行/分组空输入零行；HAVING 仅 TRUE；部分失败清理；重扫。

现有素材 [aggregate_test.cpp](../../../libs/execution/tests/aggregate_test.cpp)、[execution_differential_test.cpp](../../../libs/execution/tests/execution_differential_test.cpp) 可能跨越多题，不能把它们当作本题已经注册的隔离测试。完成后按课程规定的单元入口验证；独立注册状态是 `pending-isolated-test-registration`。
