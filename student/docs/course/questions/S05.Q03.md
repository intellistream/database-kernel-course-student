# S05.Q03 每聚合 DISTINCT

[返回阶段指南](../stages/S05.md)｜[题目总览](../README.md)

本题尚未注册独立单元测试；下列现有测试是阅读和集成验证素材，完成后需由课程维护者补齐隔离注册。

## 这题要解决什么

同一组同时计算 `COUNT(DISTINCT x)` 和 `SUM(DISTINCT x)` 时，它们各自都要独立判断 1、1、2；换组后已见值也必须重新开始。

完成后，你能按“组 × 聚合”维护 DISTINCT 状态，正确处理 NULL 和 rescan，而不把全行 Unique 当成替代方案。

## 先走通一个小例子

同一组输入 `x=1,1,2`，同时计算 `COUNT(DISTINCT x)` 和 `SUM(DISTINCT x)`；每个聚合都应各自看到 1、2。换组后必须重新开始。

## 分步实现

- 在组状态内为每个 DISTINCT 聚合配置独立已见集合。
- 先判断值是否可接受，再决定是否送入累加器。
- 处理 NULL 的聚合特有规则。
- 在 open/rescan/清理时清空每组每聚合集合。

## 必须守住的约束

- 按聚合、按组隔离，不可用全行 Unique 代替。
- 两个 DISTINCT 聚合不能共享已见状态。
- 重扫不得保留上次集合。

## 怎样验证

验收必须覆盖：两个 DISTINCT 聚合互不污染；NULL；组间隔离；rescan 清空集合。
