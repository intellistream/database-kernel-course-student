# S10 WAL、检查点与恢复

[题目总览](../README.md) · [练习流程](../getting-started.md)

## 贯穿本阶段的思考

日志写入、日志耐久、页面重做和事务提交分别记录。分别检查字节边界、页 LSN 和事务收尾。

## 动手前确认

- 从每题实际的 `LAB-Sxx.Qyy` 区间定位实现，不按整个文件分配题目。
- 先用指南中的小例子检查输入、状态和失败点，再扩大场景。
- 测试文件是素材；独立注册状态和 [夹具契约](../fixtures.md) 决定目前能怎样验收。
