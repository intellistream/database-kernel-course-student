# 实验指南

文档按题目组织。请从 [十阶段总览](course/README.md) 或 [83 题索引](../problem.md) 找到练习，再进入对应的 `Sxx.Qyy.md`。

每题指南说明要解决的问题、先读的概念、源码入口、最小例子、实现里程碑、关键约束、验证方式和思考提示。各题按指南选读相关知识。

共用内容集中在四份短文档：

- [开始练习](course/getting-started.md)：选题、构建、实现和提交。
- [共用约定](course/conventions.md)：类型、所有权、错误和算子生命周期。
- [夹具与验收边界](course/fixtures.md)：测试端口、固定输入与独立验收现状。
- [格式速查](course/formats.md)：不可随意更改的持久化字节布局。

[运行器说明](../labs/README.md) 记录命令与注册规则；[题库清单](course/question-bank.json) 和 [实验清单](../labs/manifest.json) 保存机器可读的题目范围、算法区间和测试登记。
